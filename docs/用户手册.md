# Showit 主讲演示手册

适用版本：**v0.3.11**

Showit 是浏览器演示控制台。业务系统始终运行在真实浏览器标签页中，主讲人在侧边栏控制台中控制讲稿、步骤、计时、标注和观众画面。

## 1. 安装

1. 下载 `Showit_Extension_<版本>.zip` 和对应的 `.sha256` 文件。
2. 校验并解压扩展包：

```bash
sha256sum -c Showit_Extension_<版本>.zip.sha256
```

3. 打开 `chrome://extensions`，开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后的扩展目录。
5. 点击 Chrome 工具栏中的 Showit 图标，打开侧边栏控制台。

Showit 使用 Chrome 浏览器的本地存储保存项目。请定期从项目库导出 `.showit` 备份。

## 2. 准备演示项目

### 使用内置示例

首次使用时，项目库会创建：

```text
云枢 · 五角色能力治理闭环
```

这是 Showit 自带的离线能力示例，不需要启动外部服务。

### 使用自己的业务系统

1. 在项目库点击“新建项目”，或点击“导入”导入 `.showit` 项目。
2. 打开项目编辑器，添加业务连接器。
3. 填写业务系统地址、页面、角色、讲稿和步骤。
4. 为每个填写步骤选择定位器和数据来源：
   - 固定值
   - 项目变量
   - 页面变量
   - 敏感变量
5. 为登录、密码、MFA、文件选择等页面配置隐私遮挡。
6. 发布项目版本，开始演示前确认预检没有错误。

首次运行项目时，Chrome 会请求业务网站访问权限。按提示允许对应站点。

### 使用独立 Northstar Demo（开发测试）

仓库中的 `demo/` 是一个独立的普通业务系统示例，不属于 Showit 内置示例。

```bash
npm run demo:dev
```

然后在 Showit 项目库导入：

```text
demo/Northstar_Supply_Demo.showit
```

Demo 地址为 `http://127.0.0.1:3001`。它包含登录、运营概览、库存和订单页面。

## 3. 开始演示

1. 在侧边栏项目库选择项目，点击“运行”。
2. 演示开始后，业务系统会作为真实标签页打开，侧边栏继续作为主讲控制台。
3. 使用侧边栏控制：
   - 上一页 / 下一页 / 跳页
   - 上一步骤 / 下一步骤
   - 开始、暂停、重置计时
   - 自动翻页
   - 激光笔、圈选、撤销
   - 黑屏、白屏、冻结
   - 遮罩画面
   - 离线备用
4. 项目结束后点击“结束演示”。

快捷键：

| 快捷键 | 操作 |
|---|---|
| `←` / `→` | 上一页 / 下一页 |
| `↑` / `↓` | 上一步骤 / 下一步骤 |
| `Space` | 开始 / 暂停计时 |
| `L` | 激光笔 |
| `C` | 圈选 |
| `B` / `W` / `F` | 黑屏 / 白屏 / 冻结 |
| `P` | 遮罩画面 |
| `A` | 自动翻页 |
| `R` | 排练 |
| `Esc` | 退出当前工具或对话框 |

每次点击“运行”都是新的一场演示，从第 1 页开始。

## 4. 给观众看画面

Showit 有两种观众方式。

### 视频会议共享

1. 在控制台点击“共享画面”。
2. 视频会议软件中只共享 Showit 打开的只读观众窗口。
3. 不要共享包含侧边栏的主讲窗口。

观众窗口不显示控制台、备注、计时器或敏感变量。

真实业务页首次投送前，需要在业务标签页完成画面捕获授权：

- 右键业务标签页，选择“Showit：授权画面捕获”；或
- 按 `Ctrl+Shift+9`。

工具栏中的 Showit 图标只负责打开控制台，不负责授权捕获。

### 远程观众

远程观众在自己的浏览器打开链接，不需要安装 Showit。

1. 启动并部署 Showit 中继服务。
2. 控制台点击“远程观众”。
3. 填写中继地址，点击“检查连接”。
4. 点击“开启远程观众”。
5. 复制观看链接发给观众。
6. 演示结束后点击“结束远程观众”。

本机开发时可启动：

```bash
npm run relay:dev
```

默认地址：

```text
http://127.0.0.1:8787
```

中继只转发 Showit 源端捕获并合成后的观众画面。观众不会打开业务 URL，也不会读取业务页面、Cookie、Token 或登录状态。当前采用 P2P，建议不超过 5 名观众。

## 5. 登录与隐私

- 密码、Token 和 Secret 不会保存到项目文件。
- 敏感变量只有执行到对应步骤时才会索取。
- 输入密码、MFA 或选择文件时，观众画面会自动进入隐私保护。
- 主讲人仍可以在业务标签页中完成登录。
- 敏感操作完成后，观众画面会自动恢复。
- 点击“遮罩”可以主动整屏遮挡观众画面，再点击一次恢复。
- “遮罩”与“圈选”是两项独立功能；“撤销”只撤销圈选。
- 需要长期遮挡固定区域时，使用“更多 → 框选区域”。

## 6. 演示结束

结束前：

1. 点击“结束演示”。
2. 确认业务标签和观众窗口关闭。
3. 远程观众房间自动销毁，旧链接失效。
4. 需要保留项目时，在项目库导出 `.showit` 备份。

## 7. 常见问题

| 问题 | 处理方法 |
|---|---|
| 业务页打不开 | 检查业务地址和站点权限；必要时使用“离线备用” |
| 提示业务页受阻 | 检查登录、密码、MFA 或文件选择状态；敏感输入结束后会自动恢复 |
| 提示需要捕获授权 | 在业务标签页右键授权，或按 `Ctrl+Shift+9` |
| 观众只看到保护画面 | 检查是否仍在登录或敏感操作；也可能是主动开启了“遮罩” |
| 远程观众无法连接 | 检查中继地址、端口、防火墙和中继页面的“检查连接”结果 |
| 远程链接显示 404 | 房间已结束或空闲回收，请重新开启远程观众并发送新链接 |
| 业务标签被关闭 | 在控制台点击“恢复画面标签” |
| 无痕窗口没有打开 | 在 `chrome://extensions` 的 Showit 详情中开启“允许在无痕模式下运行” |

## 8. 安全边界

Showit 的观众只接收捕获并合成后的像素画面。Showit 不保存业务账号、密码、Cookie、Token 或 Secret；观众不访问业务 URL，也不获得业务 DOM 和登录态。
