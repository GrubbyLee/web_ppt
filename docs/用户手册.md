# Showit 用户手册

适用版本：**v0.3.5**（WXT 浏览器扩展 + 可选观众中继服务）

## 1. 安装与数据

Showit 以 **Chrome 扩展**形式交付。从 Release 下载 `Showit_Extension_<version>.zip` 及其 `.sha256`，校验后解压：

```bash
sha256sum -c Showit_Extension_0.3.0.zip.sha256
```

在 `chrome://extensions` 打开“开发者模式”，选择“加载已解压的扩展程序”并指向解压目录。默认支持 Chrome；Edge/Chromium 未纳入自动验收，需要自行验证。

**观众中继（可选）**：远程观众（局域网/公网）需要单独部署 `apps/relay`（Docker，见 §10）。仅用视频会议共享时无需中继。

**数据存放**：

- 项目库、版本历史、排练记录 → 浏览器 **IndexedDB**
- 项目信任、诊断、活动项目、中继地址 → `chrome.storage.local`
- 运行会话快照 → `chrome.storage.session`（浏览器关闭即清）
- 敏感变量 → **仅存在于扩展后台进程内存中**，不写入磁盘或 `storage`；浏览器关闭或后台重启即清除

清理浏览器站点数据会删除项目库，请定期用 `.showit` 导出备份。

## 2. 本机 = 演示者

演示者在本机使用：

- **演示者窗口**：一个浏览器窗口，**左侧**是**业务系统页面**（真实标签页，不做任何内嵌），**右侧**是**侧边栏控制台**（演示者在其中控制进度）。两者同处一个窗口，因此点击控制台只移动键盘焦点，业务页面始终是可见的活动标签
- **侧边栏控制台内的项目库**：演示开始前用于查看项目数量、选择要演示的项目、编辑项目（编辑会在标签页打开编辑器）；演示开始后自动隐藏，可用控制台的「项目库」按钮随时呼出，「返回控制台」隐藏
- **工作台**（普通标签页）：项目库与项目编辑器的完整页面视图，`chrome-extension://<id>/workbench.html`；在控制台里点「编辑项目」会以独立窗口打开它，不影响演示者窗口
- （可选）**共享画面窗口**：本机上的干净只读渲染窗口，**用途是作为视频会议的共享源，或接第二显示器预览**——观众本身不在本机，只看远程中继或会议画面

扩展不预先申请任何站点权限；首次运行项目时按连接器 Origin **逐个授权**。

## 3. 观众形态（两种）

观众**从不看演示者本机**。两种形态：

| 形态 | 观众用什么看 | 是否需要中继 | 说明 |
|---|---|---|---|
| **远程观众（中继）** | 观众自己的浏览器打开分享链接 | **是**（部署 `apps/relay`） | 局域网或公网；观众免装软件 |
| **视频会议共享** | 会议软件（Webex/Zoom/腾讯会议）共享窗口 | 否 | 见 §11 |

两种形态下观众看到的都是**只读的“观众屏”**：业务系统 + 页码角标，**不含任何演讲者界面**——控制台、对话框、敏感变量输入都不会出现。

**内置演示系统的可见性**：演练控制台自身是扩展页面，**不可被浏览器捕获**。因此开启远程观众时，会话标签会切到**中继托管的演练控制台副本**（HTTP，可捕获）→ 远程观众可见，且演示结束/关闭远程后自动切回扩展页（演示者本机视图）。

## 4. 内置示例

首次打开工作台自动创建「云枢 · 五角色能力治理闭环」示例（可删除、可复制）。业务系统是**扩展内置的“云枢能力开放平台”演练控制台**，完全离线运行，无需外部服务：

- 10 个章节页 → 舞台幻灯片；8 个演示页 → 演练控制台的市场、订阅、资产目录、审批、运行洞察等视图
- 登录步骤演示**敏感变量**：演示密码**执行到该步骤时才索取**（不写磁盘，浏览器关闭即清），填写期间观众画面自动隐私保护
- 资产发布演示**高风险确认**；市场搜索链演示**验证后自动续跑**；审批演示**条件验证**（待审批 → 已通过）
- 演示页在演示者窗口内**直接渲染**，无需画面捕获授权
- 访客演示页配了离线 HTML 备用，可用“离线备用”按钮体验断网切换

旧版 LCAPIM 示例（指向 localhost:3001）在未被修改时会自动升级为新示例。

## 5. 创建项目

1. 工作台项目库 → “新建项目”，填名称进编辑器
2. 配置项目说明、默认浏览器会话（日常浏览器 / 专用演示环境=无痕窗口，需在扩展设置允许无痕）、品牌文案
3. 添加连接器：打开方式（演示标签页 / 独立浏览器窗口）、权限（仅观察 / 协助 / 自动操作）、安全模式（交互 / 请求保护=拦截写请求 / 只读强制=拦截全部写请求）。请求保护可为登录、退出、角色切换路径放行
4. 每页填标题、章节、角色、计划时长、业务 URL 模板、Markdown 脚本、结构化步骤。复制页面会连带脚本/遮罩/变量/离线备用生成全新标识；删除后自动选中相邻页
5. 为断网准备截图 / 视频 / 隔离 HTML 备用。隔离 HTML 默认不能联网；编辑器可预授权明确 Origin，演示中也可按 CSP 阻止提示**临时授权（仅本次运行）**
6. 发布前检查错误项清零 → 发布版本快照（可填发布人与变更说明）

编辑器短延迟自动保存，未保存草稿有独立恢复槽；发布版本不可直接改写，可从版本历史比较或恢复。

## 6. 导入与导出

项目库支持 `.showit` ZIP（v0.1 项目可直接导入）。普通包带完整性校验；密码包用 Argon2id + AES-256-GCM，密码不保存、无法找回。

导入第三方项目时先核对业务域名、离线 HTML、自动操作、高风险步骤、资源体积，再确认信任；内容变化后需重新确认。取消信任后仍可编辑/导出，但不能绕过确认运行。项目包不含 Cookie / Token / 密码 / 浏览器会话。

## 7. 演示运行

1. 打开侧边栏控制台（点工具栏图标），在**控制台里的项目库**选“运行”（首次弹站点授权，建议一次确认）
2. 演示开始后项目库自动隐藏，**同一个演示者窗口内新增一个演示标签页**（业务页面）：左侧业务系统、右侧控制台，因此点击控制台（激光笔、圈选、翻页、屏幕模式）不会让演示页失焦或退到后台；顶部看项目、页码、计时、观众状态。项目设为「专用演示环境（无痕窗口）」时演示页开在独立的无痕窗口，控制台同样停靠在那个窗口

  > 业务系统始终作为**真实标签页**运行，不会被嵌入 iframe：否则会出现第二个实例（登录态不一致、写操作可能重复生效），且大量站点会拒绝被框。
3. 需要给远程/会议观众画面时：远程观众见 §10；视频会议见 §11。共享真实业务页画面**需先授权捕获**（演示者窗口里的业务标签页右键“Showit：授权画面捕获”或 `Ctrl+Shift+9`；点工具栏图标只会打开控制台，不会授权）
4. 快捷键（作用于聚焦的面板）：`←/→` 翻页、`↑/↓` 步骤、`空格` 计时、`L` 激光笔、`C` 圈选、`B/W/F/P` 黑屏/白屏/冻结/隐私、`A` 自动翻页、`R` 排练、`Esc` 逐级退出
5. 控制台按用途分组，按钮都带文字：**页面**（上一页 / 跳页下拉 / 下一页）、**计时**（开始暂停 / 重置 / 排练 / 自动翻页）、**画面与投送**（隐私遮挡 / 共享画面 / 更多）、**设置 / 结束演示**；页面工具组为激光笔 / 圈选 / **撤销** / 遮罩 / 离线备用。底栏另显示总、本页、本章、剩余计时（排练可记逐页耗时，结束可填备注）
6. 顶栏「**项目库**」按钮随时呼出/隐藏项目库：演示前用它选项目、看项目数量、编辑项目；演示开始后自动隐藏，左侧完全交给业务系统
6. 自动翻页在设置、脚本编辑、页面加载或异常、屏幕控制、标注、步骤操作期间暂停；**侧边栏关闭时自动翻页暂停（计时继续），重开即恢复**
7. 演示中可直接改脚本 / 备用 URL / 遮罩 / 自动翻页设置；退出时合并回项目（未改动字段以编辑器版本为准）

规则：

- 高风险步骤必须现场确认；条件验证失败可重执行或填原因强制完成；普通步骤需显式启用才在验证成功后继续，且不跨页、不跨越高风险步骤
- “填写字段”步骤用唯一稳定定位器；值来源 = 固定值 / 项目变量 / 页面变量 / 敏感变量。敏感变量**执行到依赖它的步骤时才在侧边栏索取**（启动演示不再被阻塞），输入值不保存、仅在本次运行有效；**协助模式只聚焦高亮，自动操作模式才真正写入**
- 意外退出后后台快照可恢复（页码、计时、完成步骤不丢）；但**每次点「运行」都是新的一场**，从第 1 页与零计时开始，不会沿用上一场的进度（否则会停在末页甚至「演示结束」页上开场），业务页面标签需在侧边栏“恢复画面标签”重建
- 激光笔与圈选标注**按页保存**：翻页时当前页的标注让位给目标页，**翻回原页又会看到**；点「撤销」按画的顺序**倒序逐个清除**（可连续点，标注清空后按钮自动禁用），撤销不会退出圈选工具，可以接着画

## 8. 隐私与安全

- 密码框 / 文件选择 / 常见 MFA·SSO 登录表单 → 侧边栏显示“业务页受阻”，**观众画面同时强制隐私封面**（合成器兜底；演示者窗口保持可见以便登录，敏感输入消失后自动解除）
- 手动隐私模式（P）需演示者手动恢复；登录表单引发的自动保护自动解除
- 局部遮罩可框选或绑定 DOM 元素，演示者窗口与观众画面**同步覆盖**
- 请求保护 / 只读强制 = 扩展 DNR 规则在浏览器层拦截写方法请求，仅放行配置的登录/退出/角色切换路径
- 离线 HTML 的现场 Origin 授权只进当前会话，不写入项目或 `.showit`；观众侧离线渲染无脚本、无网络权限
- 观众侧只接收**捕获并合成后**的像素流，不打开业务 URL、不读 DOM/Cookie/登录态；**不采集音频或麦克风**

## 9. 异常处理

| 现象 | 处理 |
|---|---|
| 业务页打不开 / 异常 | 用“离线备用”切换备用内容，或检查业务系统本身 |
| 业务页面标签被误关 | 侧边栏“恢复画面标签”重建并回到当前页 |
| 提示“画面捕获需要授权” | 业务标签页右键“Showit：授权画面捕获”或 `Ctrl+Shift+9`；控制台“授权画面捕获”按钮可在手势授权后重试 |
| 新站点等待授权 | 按弹窗确认站点权限后重试 |
| **无法连接中继服务** | 检查中继是否运行、地址是否可达（含端口/防火墙）；局域网用内网 IP，公网用域名 |
| **观众链接打不开（404）** | 房间已结束或被 15 分钟空闲回收；在控制台重新开启远程观众拿新链接 |
| **远程观众看不到画面** | 确认是真实业务页（内置演示页不可捕获）；确认已完成捕获授权 |
| **公网观众卡顿** | 当前 P2P 点对点，建议 ≤5 人；更多观众待 SFU 模式 |
| 绑定遮罩失效 | 保持整页隐私保护，重选稳定元素或改用矩形遮罩 |
| 项目读取失败 | 从 `.showit` 备份导入，或从版本历史恢复 |
| 离线 HTML 资源被阻止 | 核对弹窗中的完整 Origin，仅在可信时允许本次演示，或在编辑器预授权 |
| 专用演示环境仍开普通窗口 | `chrome://extensions` → Showit 详情 → 开启“在无痕模式下允许” |

侧边栏设置中的诊断保留 7 天或 500 条（已脱敏），可导出；导出包不含截图、视频、脚本文本、完整业务 URL、Cookie、Token、密码、Basic/Bearer 凭据。

## 10. 远程观众（局域网 / 公网）

观众**无需安装任何软件**，用浏览器打开分享链接即可看“观众屏”（只读画面 + 页码角标，无演讲者界面）。

**部署中继**（`apps/relay`，无账号、无持久化，升级=替换进程）：

```bash
# 局域网：内网任意主机（SHOWIT_RELAY_BASE_URL 必须填观众能访问的地址）
cd apps/relay
docker build -t showit-relay .
docker run -p 8787:8787 -e SHOWIT_RELAY_BASE_URL=http://<内网IP>:8787 showit-relay
```

公网 = 云主机 + 域名 TLS 反代（**WSS 需透传**）。

**使用**：演示中控制台点“远程观众”→ 填中继地址（本机记忆）→ 复制弹窗里的观众链接发给观众（也可任意二维码工具）。“等待批准”模式下弹窗逐个批准、可断开单个观众；**演示结束自动销毁房间**。

**保证与边界**：

- 隐私在**源端强制**：观众收到的是捕获后已套遮罩/封面的画面；链接带不可猜测令牌；观众端禁脚本 CSP
- 当前为 **P2P 点对点**（建议 ≤5 人，上限 20）；**SFU 大房间（>5 人）尚未实现**（扩展与中继已预留 `capacity` 字段）
- **内置演示系统（demo://）是扩展页面，不可被捕获 → 远程观众看不到其画面**；远程观众面向**真实业务系统**
- 公网用浏览器内置公网 STUN；纯局域网部署无公网依赖

## 11. 观众怎么看画面（两种，且只有两种）

Showit **不为“演示者的第二块屏幕”设计**。本机只有演示者窗口（左侧业务系统 + 右侧侧边栏控制台），观众永远不看你本机。观众看到画面只有两条路：

| 方式 | 操作 | 说明 |
|---|---|---|
| **视频会议共享** | 控制台点“共享画面”开一个只读画面窗口，在会议软件里**只共享这个窗口** | 观众看到纯业务系统画面；**控制台在演示者窗口，绝不入镜**；登录表单等敏感操作自动隐私封面；无需会议软件的“区域框选” |
| **远程观众（中继）** | 见 §10：控制台开启远程观众，把链接发给观众，观众在自己浏览器打开 | 观众无需安装任何软件，链接带不可猜测令牌，只读 |

要点：

- “共享画面”窗口**不是给演讲者自己看的第二屏**，它是给视频会议共享用的干净画面源。演示时你始终看自己窗口里的业务系统。
- 会议里若直接共享“整个演示者窗口”，观众会看到控制台——**不要这么做**；共享“共享画面”窗口即可。
- 内置演示系统同样可让会议观众看到：共享“共享画面”窗口（本机渲染/镜像）。

## 12. 与 v0.1 桌面版的差异

- **v0.2**：移除 v0.1 桌面壳（Tauri）、局域网观众服务、LiveKit SFU sidecar、应用内更新器与便携版；改为纯 WXT 扩展 + 侧边栏控制台，本机为演示者
- **v0.3**：通过**独立中继服务**（`apps/relay`）提供局域网 / 公网远程观众（P2P 模式，含审批/踢出/空闲回收）；SFU 大房间与质量统计面板为后续项
- 数据合同与 `.showit` 包格式与 v0.1 **保持兼容**，可无缝迁移
