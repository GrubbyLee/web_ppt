# Showit 用户手册

## 1. 安装与数据

Windows 10/11 使用当前用户 NSIS 安装包，不需要管理员权限。Linux 使用对应架构的 AppImage 或 `.deb`。首次运行会在当前用户应用数据目录创建 SQLite 工作库。

Windows 便携 ZIP 解压后直接运行 `Showit.exe`。不要移除同目录的 Native Host、LiveKit sidecar 和许可证文件。便携版默认仍使用用户应用数据目录；关闭 Showit 后，将 `portable-data.enabled.example` 重命名为 `portable-data.enabled`，下次启动会改用程序旁的 `data` 目录。移动或升级便携版前应备份该目录。

所有安装包旁均应有同名 `.sha256` 文件。Linux 可执行：

```bash
sha256sum -c Showit_0.1.0_amd64.deb.sha256
```

## 2. 浏览器扩展

正式安装包会为已配置的 Chrome/Edge 商店扩展注册当前用户 Native Messaging Host。开发环境可构建并手动加载：

```bash
npm run build -w @showit/extension
```

在浏览器扩展管理页加载 `apps/extension/dist`。扩展不会预先申请所有站点权限；在 Side Panel 输入业务 Origin 并确认后，只授权该 Origin。

## 3. 创建项目

1. 在项目库选择“新建项目”，填写名称并进入编辑器。
2. 配置项目说明、默认浏览器会话、观众容量（5 人 P2P 或 20 人本地 SFU）、加入方式和品牌文案。
3. 添加连接器，选择扩展标签、iframe 或独立窗口模式，并设置观察、辅助或自动操作权限。连接器可选交互、扩展请求保护或本机只读代理；只读代理只接受已联调的明确 Origin，启动失败时不会回退为直接访问。
4. 为每页填写标题、章节、角色、计划时长、业务 URL、Markdown 脚本和结构化步骤。Markdown 工具栏可快速插入标题、列表、引用、代码块和演示步骤区块，源码与预览按阅读进度同步滚动。
5. 为现场网络异常准备截图、视频或隔离 HTML 备用内容。隔离 HTML 默认不能联网；编辑器可预授权明确的 HTTP(S) Origin，也可在演示中按 CSP 阻止提示临时授权。
6. 发布前查看检查结果；错误项清零后发布版本快照。

编辑器短延迟自动保存。发布版本不可直接改写；可从版本历史比较或恢复。开始演示、导入项目和发布时会保留快照。

## 4. 导入与导出

项目库支持 `.showit` ZIP 包。普通包带完整性校验；密码包使用 Argon2id 与 AES-256-GCM，密码不会保存且无法找回。

导入第三方项目时先核对业务域名、离线 HTML、自动操作、高风险步骤和资源体积，再确认信任。项目内容变化后需重新确认；演示中的“应用修改”也执行同一检查。项目库可取消项目信任，取消后仍可编辑和导出，但项目库、编辑器和直接演示路由都不能绕过确认运行。项目包不包含 Cookie、Token、密码或浏览器会话。

## 5. 演示运行

1. 在项目库选择“运行”。
2. 在顶部确认项目、章节、页码、计时和观众状态。
3. 需要真实业务标签时打开扩展 Side Panel，授权站点并选择“投送当前标签”。
4. 单屏可使用 Side Panel 控制步骤和翻页；双屏可从顶部打开本机观众屏。
5. 局域网分享在设置中选择正确的网络接口后启动，可复制链接或扫描二维码。等待批准模式下逐个批准观众；可查看连接质量并断开单个或全部观众。20 人模式会在分享期间按需启动本地 SFU，停止分享时一并关闭。
6. 使用底栏开始、暂停、重置总计时、本页计时和本章计时；排练模式会记录逐页耗时。自动翻页在设置、脚本编辑、页面加载或异常、屏幕控制、标注和步骤操作期间暂停，关闭阻塞后继续剩余时间。

高风险步骤必须现场确认。条件验证失败时可重新检查，或填写原因强制完成。普通步骤只有显式启用后才会在验证成功时继续，且不会自动跨页或跨越高风险步骤。

“填写字段”步骤必须使用唯一稳定定位器，值来源可选固定值、项目变量、页面变量或启动时敏感变量。敏感变量只在开始演示时输入，步骤保存的是变量名，不保存输入值；辅助模式只聚焦并高亮字段，只有自动操作模式才会写入普通输入框、文本域或下拉框。

运行时固定使用启动快照。意外退出后优先恢复浏览器会话缓存，其次恢复 SQLite `runtime_sessions` 中的运行快照，均不会把运行状态覆盖回项目工作库。用户明确返回项目库或退出演示时，Showit 先向观众发布结束页，再停止局域网投送、扩展请求保护和只读代理，并清除敏感变量与运行恢复槽。编辑器的未保存有效草稿使用独立恢复槽；保存成功后自动清除。

## 6. 隐私与安全

- 密码框、文件选择、常见 MFA/SSO 登录表单、未授权新域名和绑定遮罩定位失败会使观众屏进入整页隐私保护。
- 隐私保护恢复必须由演讲者手动执行。
- 局部遮罩可框选或绑定 DOM 元素，只作用于观众输出。
- 请求保护连接器会在扩展层阻止写请求，仅放行配置的登录/退出路径。
- 本机只读代理只监听 `127.0.0.1` 随机端口，将读取请求固定到连接器 Origin，并在请求到达业务系统前拒绝普通写操作；只有显式配置的登录/退出路径可放行。
- 离线 HTML 的现场 Origin 授权只进入当前演示会话。它不会写入项目、`.showit` 或观众页；重新开始演示时需要再次授权。观众页只显示无脚本、无网络权限的渲染副本。
- 局域网视频不使用公网 STUN/TURN，不采集音频或麦克风。本机第二屏和局域网观众都只接收浏览器捕获的像素流，不会打开业务 URL、读取 DOM、Cookie 或登录态。

## 7. 异常处理

| 现象 | 处理 |
|---|---|
| 业务页无法 iframe 加载 | 使用扩展标签或独立窗口，或切换备用 URL/离线内容 |
| 扩展显示桌面端断开 | 保持 Showit 运行，核对 Native Host 注册后重启浏览器 |
| 新标签进入隐私保护 | 在 Side Panel 核对并授权新 Origin，再由演讲者手动恢复正常画面 |
| 观众无法加入 | 核对所选网络接口、局域网、防火墙、链接 Token、审批状态和当前容量（P2P 5 人、SFU 20 人）；观众端会自动重连 |
| 绑定遮罩失效 | 保持整页隐私保护，重新选择稳定元素或改用矩形遮罩 |
| 第二显示器拔出 | 继续局域网演示；显示器恢复后手动重新打开观众屏 |
| 项目读取失败 | 从 `.showit` 备份导入，或从版本历史恢复快照 |
| 只读代理启动失败 | 核对连接器 Origin、网络和登录放行路径；Showit 不会自动改为直接连接 |
| 离线 HTML 资源被阻止 | 核对弹窗中的完整 Origin；仅在确认内容可信时允许本次演示，或在编辑器预授权 |
| 更新服务不可用 | 继续使用已安装版本；离线能力不受影响 |

设置中的“本机诊断”最多保留 7 天或 500 条脱敏记录。导出包不包含截图、视频、脚本文本、完整业务 URL、Cookie、Token、密码、Basic 或 Bearer 凭据。

浏览器开发模式的业务健康检查可能受目标站点 CORS 限制；演前检查也不会读取 HttpOnly Cookie、业务 Storage、企业证书、真实 SSO/MFA 状态或绕过服务器 CSP/`frame-ancestors`。正式演示前必须在目标操作系统、浏览器、网络和业务账号下完成登录、角色、嵌入策略与写保护联调。
