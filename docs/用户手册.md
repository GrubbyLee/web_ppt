# Showit 用户手册

## 1. 安装与数据

Showit 以 Chrome 扩展形式交付。从 Release 下载 `Showit_Extension_<version>.zip` 及其 `.sha256`，校验后解压：

```bash
sha256sum -c Showit_Extension_0.2.0.zip.sha256
```

在 `chrome://extensions` 打开“开发者模式”，选择“加载已解压的扩展程序”并指向解压目录。默认支持 Chrome；Edge/Chromium 未纳入自动验收，需要自行验证。

项目库、版本历史和排练记录保存在浏览器 IndexedDB 中；项目信任、诊断与活动项目保存在 `chrome.storage.local`。清理浏览器站点数据会删除项目库，请定期用 `.showit` 导出备份。浏览器关闭即清除运行会话与敏感变量（`chrome.storage.session`）。

## 2. 每日使用入口

- 点击浏览器工具栏的 Showit 图标打开**侧边栏控制台**（无演示时显示落地页与“打开工作台”）。
- 工作台（普通标签页）承载项目库与项目编辑器，地址形如 `chrome-extension://<id>/workbench.html`。
- 演示运行时会自动打开独立的**演示画面窗口**（业务页面在其中的标签页上运行）。

扩展不预先申请任何站点权限；首次运行项目时按连接器 Origin 逐个授权。

## 3. 内置示例

首次打开工作台会自动创建「云枢 · 五角色能力治理闭环」示例（可删除、可复制）。它的业务系统是**扩展内置的“云枢能力开放平台”演练控制台**，完全离线运行，无需任何外部服务：

- 10 个章节页以舞台幻灯片呈现；8 个演示页对应演练控制台的市场、订阅、资产目录、审批、运行洞察等视图。
- 登录步骤演示**敏感变量**：演示密码在启动时输入（浏览器关闭即清除），填写期间观众画面自动进入隐私保护。
- 资产发布步骤演示**高风险确认**；市场搜索链演示**验证后自动续跑**；审批步骤演示**条件验证**（状态从待审批变为已通过）。
- 观众窗口对演示页采用**本地镜像**渲染——无需画面捕获授权即可同步显示（含标注与遮罩）。
- 访客演示页配置了离线 HTML 备用，可用“离线备用”按钮体验断网切换。

旧版本内置的 LCAPIM 示例（指向 localhost:3001）在未被修改的情况下会自动升级为新示例。

## 4. 创建项目

1. 在工作台项目库选择“新建项目”，填写名称并进入编辑器。
2. 配置项目说明、默认浏览器会话（日常浏览器或专用演示环境=无痕窗口，需在扩展设置中允许无痕访问）与品牌文案。
3. 添加连接器：打开方式（演示标签页/独立浏览器窗口）、权限（仅观察、协助、自动操作）与安全模式（交互、请求保护=拦截写请求、只读强制=拦截全部写请求）。请求保护可为登录、退出和角色切换路径放行。
4. 为每页填写标题、章节、角色、计划时长、业务 URL 模板、Markdown 脚本和结构化步骤。Markdown 工具栏可快速插入标题、列表、引用、代码块和演示步骤区块，源码与预览按阅读进度同步滚动。复制页面会完整复制脚本、遮罩、变量和离线备用内容并生成全新标识；删除页面后自动选中相邻页面。
5. 为现场网络异常准备截图、视频或隔离 HTML 备用内容。隔离 HTML 默认不能联网；编辑器可预授权明确的 HTTP(S) Origin，也可在演示中按 CSP 阻止提示临时授权（仅本次运行）。
6. 发布前查看检查结果；错误项清零后发布版本快照。发布时可填写发布人与变更说明，版本列表会一并展示。

编辑器短延迟自动保存，未保存草稿有独立恢复槽；发布版本不可直接改写，可从版本历史比较或恢复。开始演示、导入项目和发布时会保留快照。

## 5. 导入与导出

项目库支持 `.showit` ZIP 包（v0.1 项目可直接导入）。普通包带完整性校验；密码包使用 Argon2id 与 AES-256-GCM，密码不会保存且无法找回。

导入第三方项目时先核对业务域名、离线 HTML、自动操作、高风险步骤和资源体积，再确认信任。项目内容变化后需重新确认。项目库可取消项目信任，取消后仍可编辑和导出，但不能绕过确认运行。项目包不包含 Cookie、Token、密码或浏览器会话。

## 6. 演示运行

1. 在项目库选择“运行”（首次会弹出站点授权，建议一次确认）。
2. 浏览器自动打开侧边栏控制台与演示画面窗口；顶部确认项目、页码、计时和观众状态。
3. 需要观众画面时点击“观众屏”打开本机观众窗口（可开多个，手动摆放到第二显示器）。首次投送需要授权画面捕获：在演示画面标签上右键选择“Showit：授权画面捕获”或按 `Ctrl+Shift+9`（工具栏图标点击只会打开控制台，不会授权）。
4. 侧边栏快捷键：`←/→` 翻页、`↑/↓` 步骤、`空格` 计时、`L` 激光笔、`C` 圈选、`B/W/F/P` 黑屏/白屏/冻结/隐私、`A` 自动翻页、`R` 排练、`Esc` 逐级退出。快捷键作用于聚焦的面板。
5. 底栏提供总计时/本页/本章/剩余时间、首页/上页/下页/末页、开始/暂停/重置计时与排练。排练会记录逐页耗时，结束时可选填备注。自动翻页在设置、脚本编辑、页面加载或异常、屏幕控制、标注和步骤操作期间暂停，关闭阻塞后继续剩余时间。**侧边栏关闭时自动翻页暂停（计时继续），重新打开即恢复。**
6. 演示中可直接修改脚本、备用 URL、遮罩和自动翻页设置；退出演示时这些修改会合并回项目，未改动的字段仍以编辑器版本为准。

高风险步骤必须现场确认。条件验证失败时可重新执行，或填写原因强制完成。普通步骤只有显式启用后才会在验证成功时继续，且不会自动跨页或跨越高风险步骤。

“填写字段”步骤必须使用唯一稳定定位器，值来源可选固定值、项目变量、页面变量或启动时敏感变量。敏感变量只在演示启动后于侧边栏输入（浏览器关闭即清除），步骤保存的是变量名，不保存输入值；辅助模式只聚焦并高亮字段，只有自动操作模式才会写入普通输入框、文本域或下拉框。

意外退出后，后台会话快照可恢复（页码、计时、完成步骤不丢）；演示画面标签需要从侧边栏“恢复画面标签”重建。

## 7. 隐私与安全

- 密码框、文件选择、常见 MFA/SSO 登录表单会使侧边栏显示“业务页受阻”，观众画面同时进入强制隐私封面（合成器兜底；演示者的标签页保持可见以便完成登录，敏感输入消失后自动解除）。
- 手动隐私模式（P）的恢复必须由演讲者手动执行；登录表单引发的自动观众保护在敏感输入消失后自动解除。
- 局部遮罩可框选或绑定 DOM 元素，演讲者标签页与观众画面同步覆盖。
- 请求保护/只读强制由扩展 DNR 规则在浏览器层拦截写方法请求，仅放行配置的登录、退出和角色切换路径。
- 离线 HTML 的现场 Origin 授权只进入当前演示会话，不写入项目或 `.showit`；观众窗口的离线渲染无脚本、无网络权限。
- 观众窗口只接收浏览器捕获并合成的像素流，不会打开业务 URL、读取 DOM、Cookie 或登录态；不采集音频或麦克风。

## 8. 异常处理

| 现象 | 处理 |
|---|---|
| 业务页打不开/异常 | 用“离线备用”按钮切换备用内容，或检查业务系统本身 |
| 会话标签被误关 | 侧边栏“恢复画面标签”重建窗口并回到当前页 |
| 提示“画面捕获需要授权” | 在演示画面标签上右键选择“Showit：授权画面捕获”，或按 Ctrl+Shift+9；控制台中的“授权画面捕获”按钮可在手势授权后重试 |
| 新站点等待授权 | 按弹窗确认站点权限后重试 |
| 观众窗口黑屏/“正在连接” | 先完成画面捕获授权；确认观众窗口与演示在同一浏览器 |
| 绑定遮罩失效 | 保持整页隐私保护，重新选择稳定元素或改用矩形遮罩 |
| 项目读取失败 | 从 `.showit` 备份导入，或从版本历史恢复快照 |
| 离线 HTML 资源被阻止 | 核对弹窗中的完整 Origin；仅在确认内容可信时允许本次演示，或在编辑器预授权 |
| 专用演示环境仍开普通窗口 | 在 `chrome://extensions` 的 Showit 详情中开启“在无痕模式下允许” |

侧边栏设置中的诊断最多保留 7 天或 500 条脱敏记录，可导出。导出包不包含截图、视频、脚本文本、完整业务 URL、Cookie、Token、密码、Basic 或 Bearer 凭据。

## 9. 远程观众（局域网 / 公网）

观众无需安装任何软件，用自己的浏览器打开分享链接即可观看“观众屏”（只读画面 + 页码角标，不含任何演讲者界面）：

1. 部署中继（`apps/relay`）：局域网 `docker run -p 8787:8787 showit-relay`；公网 = 云主机 + 域名 TLS 反代（WSS 透传）。中继无账号、无持久化，升级即替换进程。
2. 演示中在控制台点“远程观众”，填中继地址（本机记忆），复制弹窗中的观众链接发给观众（也可用任意二维码工具）。
3. 项目配置为“等待批准”时，弹窗中逐个批准观众；可随时断开单个观众。
4. 演示结束自动销毁房间；房间 15 分钟无活动也会被中继自动回收。

隐私保证：观众收到的是**源端合成后**的画面（遮罩/封面/登录保护在捕获侧已强制）；观众链接带不可猜测令牌；观众端禁脚本 CSP。

注意：远程观众走公网时使用公网 STUN（浏览器内置）；纯局域网部署无公网依赖。真实业务页的远程画面同样需要先完成画面捕获授权。

## 10. 与 v0.1 桌面版的差异

v0.2 移除了局域网观众服务（HTTP 链接/二维码/审批/踢出/质量统计/网络接口选择）、LiveKit SFU（20 人）、应用内更新器与便携版。本机观众窗口数量不再受软件限制。`.showit` 项目包格式与数据合同保持兼容，可无缝迁移。
