# Showit 用户手册

适用版本：**v0.3.0**（WXT 浏览器扩展 + 可选观众中继服务）

## 1. 安装与数据

Showit 以 **Chrome 扩展**形式交付。从 Release 下载 `Showit_Extension_<version>.zip` 及其 `.sha256`，校验后解压：

```bash
sha256sum -c Showit_Extension_0.3.0.zip.sha256
```

在 `chrome://extensions` 打开“开发者模式”，选择“加载已解压的扩展程序”并指向解压目录。默认支持 Chrome；Edge/Chromium 未纳入自动验收，需要自行验证。

**观众中继（可选）**：局域网/公网观众需要单独部署 `apps/relay`（Docker，见 §10）。只在本机演示（本机观众窗口或视频会议共享）时无需中继。

**数据存放**：

- 项目库、版本历史、排练记录 → 浏览器 **IndexedDB**
- 项目信任、诊断、活动项目、中继地址 → `chrome.storage.local`
- 运行会话快照、敏感变量 → `chrome.storage.session`（浏览器关闭即清）

清理浏览器站点数据会删除项目库，请定期用 `.showit` 导出备份。

## 2. 每日使用入口

- 点击浏览器工具栏 Showit 图标 → **侧边栏控制台**（无演示时显示落地页与“打开工作台”）
- **工作台**（普通标签页）：项目库 + 项目编辑器，`chrome-extension://<id>/workbench.html`
- **演示画面窗口**：演示运行时自动打开的独立窗口，业务页面在其中的标签页上运行
- **观众窗口**：本机观众屏（可开多个，手动摆到第二显示器/投影）

扩展不预先申请任何站点权限；首次运行项目时按连接器 Origin **逐个授权**。

## 3. 观众形态一览（三种，按需选用）

| 形态 | 观众用什么看 | 是否需要中继 | 适用于 |
|---|---|---|---|
| **本机观众窗口** | 同一浏览器的独立窗口 | 否 | 单机双屏 / 投影给现场客户 |
| **远程观众（中继）** | 观众自己的浏览器，打开分享链接 | **是**（部署 `apps/relay`） | 局域网会议室 / 公网远程客户 |
| **视频会议共享** | 会议软件共享某个窗口 | 否 | Webex/Zoom/腾讯会议等 |

三者的观众画面**都是只读的“观众屏”**：业务系统 + 页码角标，不含任何演讲者界面（控制台、对话框、敏感变量输入均不出现）。

**重要边界**：内置演示系统（见 §4）是扩展内页面，**不可被浏览器捕获**——

- 本机观众窗口 / 视频会议共享观众窗口 → ✅ 可看（本机镜像渲染）
- 远程观众中继 → ⚠️ 仅**真实业务系统**可见；内置演示页远程观众会停在“等待演示画面”

## 4. 内置示例

首次打开工作台自动创建「云枢 · 五角色能力治理闭环」示例（可删除、可复制）。业务系统是**扩展内置的“云枢能力开放平台”演练控制台**，完全离线运行，无需外部服务：

- 10 个章节页 → 舞台幻灯片；8 个演示页 → 演练控制台的市场、订阅、资产目录、审批、运行洞察等视图
- 登录步骤演示**敏感变量**：演示密码启动时输入（浏览器关闭即清），填写期间观众画面自动隐私保护
- 资产发布演示**高风险确认**；市场搜索链演示**验证后自动续跑**；审批演示**条件验证**（待审批 → 已通过）
- 访客演示页配了离线 HTML 备用，可用“离线备用”按钮体验断网切换

旧版 LCAPIM 示例（指向 localhost:3001）在未被修改时会自动升级为新示例。

## 5. 创建项目

1. 工作台项目库 → “新建项目”，填名称进编辑器
2. 配置项目说明、默认浏览器会话（日常浏览器 / 专用演示环境=无痕窗口，需在扩展设置允许无痕）、品牌文案
3. 添加连接器：打开方式（演示标签页 / 独立浏览器窗口）、权限（仅观察 / 协助 / 自动操作）、安全模式（交互 / 请求保护=拦截写请求 / 只读强制=拦截全部写请求）。请求保护可为登录、退出、角色切换路径放行
4. 每页填标题、章节、角色、计划时长、业务 URL 模板、Markdown 脚本、结构化步骤。复制页面会连带脚本/遮罩/变量/离线备用生成全新标识；删除后自动选中相邻页
5. 为断网准备截图 / 视频 / 隔离 HTML 备用。隔离 HTML 默认不能联网；编辑器可预授权明确 Origin，演示中也可按 CSP 阻止提示**临时授权（仅本次运行）**
6. 发布前检查错误项清零 → 发布版本快照（可填发布人与变更说明）

编辑器短延迟自动保存，未保存草稿有独立恢复槽；发布版本不可直接改写，可从版本历史比较或恢复。

## 6. 导入与导出

项目库支持 `.showit` ZIP（v0.1 项目可直接导入）。普通包带完整性校验；密码包用 Argon2id + AES-256-GCM，密码不保存、无法找回。

导入第三方项目时先核对业务域名、离线 HTML、自动操作、高风险步骤、资源体积，再确认信任；内容变化后需重新确认。取消信任后仍可编辑/导出，但不能绕过确认运行。项目包不含 Cookie / Token / 密码 / 浏览器会话。

## 7. 演示运行

1. 项目库选“运行”（首次弹站点授权，建议一次确认）
2. 自动打开侧边栏控制台 + 演示画面窗口；顶部看项目、页码、计时、观众状态
3. 需要观众画面点“观众屏”开本机观众窗口；**首次投送真实业务页需授权捕获**：在演示画面标签右键“Showit：授权画面捕获”或按 `Ctrl+Shift+9`（点工具栏图标只会打开控制台，不会授权）
4. 快捷键（作用于聚焦的面板）：`←/→` 翻页、`↑/↓` 步骤、`空格` 计时、`L` 激光笔、`C` 圈选、`B/W/F/P` 黑屏/白屏/冻结/隐私、`A` 自动翻页、`R` 排练、`Esc` 逐级退出
5. 底栏：总/本页/本章/剩余计时、首页/上页/下页/末页、计时开始/暂停/重置、排练（记逐页耗时，结束可填备注）
6. 自动翻页在设置、脚本编辑、页面加载或异常、屏幕控制、标注、步骤操作期间暂停；**侧边栏关闭时自动翻页暂停（计时继续），重开即恢复**
7. 演示中可直接改脚本 / 备用 URL / 遮罩 / 自动翻页设置；退出时合并回项目（未改动字段以编辑器版本为准）

规则：

- 高风险步骤必须现场确认；条件验证失败可重执行或填原因强制完成；普通步骤需显式启用才在验证成功后继续，且不跨页、不跨越高风险步骤
- “填写字段”步骤用唯一稳定定位器；值来源 = 固定值 / 项目变量 / 页面变量 / 启动时敏感变量。敏感变量启动后在侧边栏输入（不保存输入值）；**协助模式只聚焦高亮，自动操作模式才真正写入**
- 意外退出后后台快照可恢复（页码、计时、完成步骤不丢），演示画面标签需在侧边栏“恢复画面标签”重建

## 8. 隐私与安全

- 密码框 / 文件选择 / 常见 MFA·SSO 登录表单 → 侧边栏显示“业务页受阻”，**观众画面同时强制隐私封面**（合成器兜底；演讲者标签页保持可见以便登录，敏感输入消失后自动解除）
- 手动隐私模式（P）需演讲者手动恢复；登录表单引发的自动保护自动解除
- 局部遮罩可框选或绑定 DOM 元素，演讲者标签页与观众画面**同步覆盖**
- 请求保护 / 只读强制 = 扩展 DNR 规则在浏览器层拦截写方法请求，仅放行配置的登录/退出/角色切换路径
- 离线 HTML 的现场 Origin 授权只进当前会话，不写入项目或 `.showit`；观众侧离线渲染无脚本、无网络权限
- 观众窗口只接收**捕获并合成后**的像素流，不打开业务 URL、不读 DOM/Cookie/登录态；**不采集音频或麦克风**

## 9. 异常处理

| 现象 | 处理 |
|---|---|
| 业务页打不开 / 异常 | 用“离线备用”切换备用内容，或检查业务系统本身 |
| 会话标签被误关 | 侧边栏“恢复画面标签”重建并回到当前页 |
| 提示“画面捕获需要授权” | 演示画面标签右键“Showit：授权画面捕获”或 `Ctrl+Shift+9`；控制台“授权画面捕获”按钮可在手势授权后重试 |
| 新站点等待授权 | 按弹窗确认站点权限后重试 |
| 观众窗口黑屏 / “正在连接” | 先完成捕获授权；确认观众窗口与演示在同一浏览器 |
| **无法连接中继服务** | 检查中继是否运行、地址是否可达（含端口/防火墙）；局域网用内网 IP，公网用域名 |
| **观众链接打不开（404）** | 房间已结束或被 15 分钟空闲回收；在控制台重新开启远程观众拿新链接 |
| **远程观众看不到画面** | 确认是真实业务页（内置演示页不可捕获）；确认已完成捕获授权 |
| **公网观众卡顿** | 观众数与带宽：当前 P2P 点对点，建议 ≤5 人；更多观众待 SFU 模式 |
| 绑定遮罩失效 | 保持整页隐私保护，重选稳定元素或改用矩形遮罩 |
| 项目读取失败 | 从 `.showit` 备份导入，或从版本历史恢复 |
| 离线 HTML 资源被阻止 | 核对弹窗中的完整 Origin，仅在可信时允许本次演示，或在编辑器预授权 |
| 专用演示环境仍开普通窗口 | `chrome://extensions` → Showit 详情 → 开启“在无痕模式下允许” |

侧边栏设置中的诊断保留 7 天或 500 条（已脱敏），可导出；导出包不含截图、视频、脚本文本、完整业务 URL、Cookie、Token、密码、Basic/Bearer 凭据。

## 10. 远程观众（局域网 / 公网）

观众**无需安装任何软件**，用浏览器打开分享链接即可看“观众屏”（只读画面 + 页码角标，无演讲者界面）。

**部署中继**（`apps/relay`，无账号、无持久化，升级=替换进程）：

```bash
# 局域网：内网任意主机（SHOWIT_RELAY_BASE_URL 必须填观众能访问的地址）
cd apps/relay
docker build -t showit-relay .
docker run -p 8787:8787 -e SHOWIT_RELAY_BASE_URL=http://<内网IP>:8787 showit-relay
```

公网 = 云主机 + 域名 TLS 反代（**WSS 需透传**）。

**使用**：演示中控制台点“远程观众”→ 填中继地址（本机记忆）→ 复制弹窗里的观众链接发给观众（也可任意二维码工具）。“等待批准”模式下弹窗逐个批准、可断开单个观众；**演示结束自动销毁房间**。

**保证与边界**：

- 隐私在**源端强制**：观众收到的是捕获后已套遮罩/封面的画面；链接带不可猜测令牌；观众端禁脚本 CSP
- 当前为 **P2P 点对点**（建议 ≤5 人，上限 20）；**SFU 大房间（>5 人）尚未实现**（扩展与中继已预留 `capacity` 字段）
- **内置演示系统（demo://）是扩展页面，不可被捕获 → 远程观众看不到其画面**；远程观众面向**真实业务系统**
- 公网用浏览器内置公网 STUN；纯局域网部署无公网依赖

## 11. 视频会议共享屏幕（演示方式 2）

演示者屏幕 = **演示画面窗口（业务系统）+ 侧边栏控制台**；观众只看业务系统。推荐做法：

| 做法 | 操作 | 效果 |
|---|---|---|
| **共享“观众窗口”（推荐）** | 会议软件选“共享窗口”→ 选 Showit 观众屏 | 观众看到纯业务系统只读画面；**控制台在别的窗口，绝不入镜**；登录表单等敏感操作自动隐私封面；无需视频会议“区域框选” |
| 共享“业务画面窗口”（轻量回退） | 直接共享会话窗口 | 最简单，但**无自动隐私保护**（观众看到的就是你看到的，含光标）；控制台须留在其他窗口 |

内置演示系统用**共享观众窗口**即可远程观看（本机镜像，可共享），不受 §10 的“不可捕获”限制。

## 12. 与 v0.1 桌面版的差异

- **v0.2**：移除 v0.1 桌面壳（Tauri）、局域网观众服务、LiveKit SFU sidecar、应用内更新器与便携版；改为纯 WXT 扩展 + 侧边栏控制台 → 本机观众窗口数量不再受软件限制
- **v0.3**：通过**独立中继服务**（`apps/relay`）恢复局域网 / 公网观众（P2P 模式，含审批/踢出/空闲回收）；SFU 大房间与质量统计面板为后续项
- 数据合同与 `.showit` 包格式与 v0.1 **保持兼容**，可无缝迁移
