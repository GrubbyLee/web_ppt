# Showit 演示工作台产品需求文档

## 1. 产品定位

Showit 是面向产品演示、售前交流、客户培训和内部评审的网页演示工作台。它把“演示页面”“演讲备注”“讲解脚本”“真实业务系统”“观众屏同步”和“演示计时”组合成一个可配置的演示项目。

Showit 不要求演示对象是固定产品。任何可访问的 Web 页面都可以作为中左区域的业务画面；演示者可以通过中右区域的 Markdown 脚本控制讲解节奏，通过底部控制区管理翻页、计时和排练。

## 2. 目标用户

| 用户 | 主要任务 |
|---|---|
| 演讲者 | 使用备注和脚本完成现场演示，控制页面、计时、观众屏和标注 |
| 售前/产品经理 | 创建演示项目，配置业务系统 URL、脚本和角色步骤 |
| 培训人员 | 使用排练模式复盘讲解节奏、备注和页面顺序 |
| 评审人员 | 查看演示项目、业务链路和页面状态 |
| 管理员 | 管理项目、成员、访问权限、版本和发布状态 |

## 3. 核心概念

| 概念 | 定义 |
|---|---|
| 演示项目 | 一套可保存、复制、发布和运行的演示配置 |
| 演示页面 | 一个讲解步骤，对应一个业务 URL、页面标题、角色和备注 |
| 业务画面 | 页面步骤中嵌入的真实 Web 页面或受控 iframe 页面 |
| 讲解脚本 | 支持 Markdown 的演讲内容，包含现场台词、操作、预期结果、转场和异常处理 |
| 演示会话 | 一次正在运行的演示，包含当前页、计时、观众屏连接和标注状态 |
| 观众屏 | 面向观众的只读画面输出，不显示演讲者备注；通过视频会议共享窗口或中继链接提供给观众 |
| 连接器 | 业务系统、静态网页、URL 模板或应用内页面的访问配置 |

## 4. 功能需求

### 4.1 演示项目管理

- 创建、编辑、复制、归档和删除演示项目。
- 配置项目名称、封面、说明、默认布局、默认计时策略和观众屏策略。
- 项目支持草稿、已发布、已归档状态。
- 项目支持版本记录，发布后保留版本号、发布人、发布时间和变更说明。
- 支持从已有项目复制后再编辑，复制结果与原项目的脚本、页面和连接器互不影响。
- 支持项目级访问权限：仅自己、团队成员、通过链接访问。

### 4.2 页面与流程配置

- 页面支持拖拽排序、复制、删除、禁用和跳转。
- 每个页面配置：标题、章节、预计时长、业务 URL、URL 参数、页面角色、页面标签、讲解目标、转场说明和异常处理。
- 页面支持指定 URL 打开方式：当前业务画面、独立窗口、观众屏、预览缩略图。
- 支持固定页面、业务系统页面、外部链接页面和结束页四类页面。
- 页面切换时同步更新中左业务画面、中右脚本、底部页码和观众屏。
- 页面加载失败时显示 URL、HTTP 状态、连接器名称、重试按钮和替代页面入口。
- 支持页面预加载和下一页预加载；预加载失败不能阻塞当前页。

### 4.3 业务系统连接

- 支持配置任意 HTTP/HTTPS URL。
- 支持 URL 模板变量，如项目变量、环境变量、页面变量和当前角色变量。
- 支持查询参数、Hash、Headers、基础认证说明和连接器环境。
- 支持 iframe 沙箱权限配置，并提供允许项说明。
- 支持 CSP、`frame-ancestors`、跨域、Cookie、Storage 和 Referrer Policy 检查。
- 支持只读演示代理模式：GET/HEAD/OPTIONS 放行，业务写操作默认拦截并返回明确错误。
- 支持登录操作放行策略；登录、退出和角色切换不应被只读保护误拦截。
- 支持业务系统角色状态回传，演示控制台显示“角色就绪、角色不匹配、未登录、连接异常”。
- 支持 URL 健康检查、页面标题检查、加载超时和资源失败统计。
- 禁止把业务页面静态截图当作已接入的真实系统；静态截图只能作为明确标记的离线备份。

### 4.4 Markdown 讲解脚本

- 中右脚本编辑器支持 Markdown：标题、列表、引用、代码、表格、链接和强调。
- 支持“编辑模式”和“演示模式”；演示模式渲染 Markdown，不显示编辑控件。
- 脚本内容按页面保存，支持自动保存、手动保存、草稿恢复和版本对比。
- 脚本支持结构化区块：现场讲述、操作步骤、预期结果、转场、舞台提示、异常处理和备用讲法。
- 支持脚本内引用当前页面名称、角色、URL、业务对象和演示变量。
- 支持备注字号调整、备注区域滚动、当前段落定位和脚本搜索。
- 支持脚本内容导入和导出 Markdown；导出结果不得包含 Token、Cookie 或密码。
- Markdown 渲染必须进行 HTML 清理，禁止脚本注入和任意 iframe 嵌套。

### 4.5 演讲者控制台

- 顶部区域显示项目名称、预计总时长、当前章节、观众屏连接状态、自动翻页状态、检查、设置、重新打开观众屏和退出。
- 中左区域显示真实业务页面；顶部显示页面选择、刷新、系统登录、激光、圈选、清除和当前页面状态。
- 中右区域显示标题、页面目标、Markdown 备注、保存状态和字号控制。
- 底部区域显示总计时、本页计时、剩余/超时状态、首个页面、上个页面、下个页面、最后页面、开始计时、重置计时和排练。
- 以上功能均须在产品化版本保留，不因改造布局而删除。
- 中左与中右默认比例为 5:4；支持拖动分隔线调整比例，限制在 2:1 至 1:1 之间。
- 支持布局预设：均衡、页面优先、备注优先；用户可以保存项目默认布局。
- 控件支持键盘快捷键、焦点状态和 tooltip。

### 4.6 观众屏与同步

- 演讲者屏和观众屏使用同一个会话 ID。
- 当前页、跳转、黑屏、白屏、冻结、激光点、圈选和结束状态同步到观众屏。
- 观众屏不显示备注、项目管理控件、计时器和脚本编辑器。
- 支持视频会议共享用的只读观众窗口，以及通过中继服务分享观众链接；不提供第二显示器专用输出。
- 观众屏断开后显示未连接，恢复后自动请求当前状态并校正页码。
- 同步消息必须校验来源、会话 ID、消息类型、序列号和 nonce。
- 观众屏无法访问业务 URL时，不影响演讲者屏操作。

### 4.7 计时与排练

- 支持项目总计时、本页计时、章节计时和预计完成时间。
- 支持开始、暂停、继续和重置。
- 支持单页预计分钟数和自动翻页秒数；自动翻页默认关闭。
- 脚本编辑、设置弹窗、页面加载、观众屏冻结和标注时可暂停自动翻页。
- 排练模式记录每页实际耗时、计划耗时、超时情况和排练备注。
- 支持最近 5 次排练记录查看和导出。

### 4.8 标注与屏幕控制

- 激光笔显示短暂红色光点并同步到观众屏。
- 圈选支持拖拽绘制椭圆，支持清除和同步。
- 支持清除当前页面所有标注。
- 支持观众屏黑屏、白屏和冻结；演讲者屏仍可继续翻页和操作。
- 标注层默认不拦截业务页面交互，只有启用圈选或激光后才接收指针事件。

### 4.9 演前检查与异常

- 检查项目配置、业务 URL、当前页面尺寸、业务页加载、观众输出窗口或中继连接、同步通道、图片资源和浏览器能力。
- 检查结果分为正常、建议和异常，并给出修复动作。
- 业务页面加载失败支持重试、打开新窗口和切换备用 URL。
- 演示期间捕获运行时异常和网络错误，提供 traceId 或错误上下文。
- 检查结果支持导出为演前记录。

## 5. 非功能需求

- 首屏控制台在本地环境 2 秒内可交互；业务 iframe 单独计时，不阻塞外壳。
- 1440×900、1024×768、375×812 三种视口无横向溢出和文字遮挡。
- 所有项目配置、脚本和会话状态支持自动保存和恢复。
- Markdown、URL 和消息通信具备 XSS、点击劫持、跨源消息和敏感信息防护。
- 业务系统 URL、Cookie、Token、Secret 和脚本敏感字段不得写入日志。
- 业务系统不可用时，演示外壳仍能进入离线预览或继续下一页。
- 项目配置变更支持版本、审计和回滚。

## 6. 验收标准

- 创建一个项目，配置至少 18 个页面，每页有业务 URL 和 Markdown 脚本。
- 从第 1 页切换到第 18 页，中左 URL、中右脚本、页码和观众屏保持一致。
- 拖动中左/中右分隔线后，刷新页面仍保留布局比例。
- 在脚本中编辑 Markdown，刷新页面后内容、字号和滚动位置按设计恢复。
- 观众窗口或中继观看页可独立打开；演讲者执行翻页、黑屏、冻结、激光和圈选时，观众画面同步正确。
- 真实业务系统登录、退出和角色提示可用，业务写操作保护不被绕过。
- 计时、自动翻页、排练记录和异常恢复通过演示回归。
- 断开业务 URL、观众屏和同步通道后，系统均显示明确状态且可恢复。
