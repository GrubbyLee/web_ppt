# Showit v0.1.0 发布验收记录

## 1. 结论

- 记录日期：2026-09-13（Asia/Shanghai）；2026-09-26 升级为正式发布记录。
- 源码基线：本记录所在提交
- 本地结论：源码质量门禁、浏览器回归、扩展回归、SFU 冒烟、Linux 打包和 AppImage 启动检查通过。

- 正式标签：`v0.1.0`。签名私钥、真实扩展 ID 和更新端点仍未配置，标签构建流水线可能因缺少 `TAURI_SIGNING_PRIVATE_KEY`、`SHOWIT_UPDATER_PUBKEY`、`SHOWIT_EXTENSION_IDS` 而失败，这些属于发布基础设施欠账，与代码质量无关。

- Ubuntu 22.04、Ubuntu 24.04、Debian 12：真实系统安装、升级与卸载矩阵。
