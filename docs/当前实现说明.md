# 当前实现说明

适用版本：**v0.3.11+**

本文是仓库当前实现的唯一技术与产品基线。历史方案、早期需求和已作废设计不再作为开发依据。

## 产品定位

Showit 是面向主讲人的 Web 业务演示运行时：

- 业务系统运行在真实浏览器标签页中，不嵌入业务 iframe。
- 主讲人在 Chrome 侧边栏控制台中管理项目、讲稿、步骤、计时、标注和观众画面。
- 观众通过视频会议共享的只读窗口，或 `apps/relay` 中继链接观看。
- 观众只接收源端捕获并合成后的像素画面，不访问业务 URL、DOM、Cookie 或登录态。


## 运行模型

后台 service worker 是唯一运行状态源：

- `session/machine.ts` 使用纯函数处理会话动作。
- `background.ts` 负责标签页、连接器、捕获、DNR 和中继编排。
- `chrome.storage.session` 保存可恢复的运行快照；计时使用时间戳模型。
- `offscreen` 执行 `tabCapture → canvas 合成 → WebRTC`。
- 侧边栏、业务标签页、共享观众窗口和远程观众都通过状态广播同步。

## 业务项目

项目包使用 `.showit` 格式，包含：

- 页面、讲稿和步骤
- 业务 URL 与连接器
- 项目变量和运行时敏感变量定义
- 隐私遮罩和离线备用内容
- 观众品牌与输出配置

账号、密码、Cookie、Token 和 Secret 不进入项目包。敏感值只在当前运行内存中存在。

导入项目必须经过结构、域名、自动操作、离线资源和高风险步骤审查；项目内容变化后需要重新信任。

## 观众输出

### 视频会议

Showit 打开只读共享画面窗口。视频会议软件只共享这个窗口，不共享包含侧栏控制台的演示者窗口。

### Relay

`apps/relay` 是独立无持久化中继，只处理房间、令牌、信令和观众观看页，不打开业务页面。

本机开发推荐：

```bash
npm run start:local
```

该命令启动独立 Demo、Relay Companion 和扩展开发服务：

```text
Showit：6666
独立 Demo：7777
Relay：8888（自动回退）
Companion：9999（自动回退）
```

也可以单独启动：

```bash
npm run demo:dev
npm run relay:companion
npm run dev
```

远程观看当前使用 P2P，建议不超过 5 名观众；公网连接依赖网络环境，TURN/SFU 尚未作为当前能力承诺。

## 安全边界

- DNR 默认拦截业务写请求，只放行明确配置的登录、退出和角色切换路径。
- 密码、MFA、文件选择等敏感输入会强制观众隐私封面。
- 合成器层再次执行封面和遮罩，不能只依赖页面 UI。
- Relay 不保存业务内容、凭据或登录状态。
- 离线 HTML 默认无脚本、无网络；临时网络授权只存在于当前运行。
