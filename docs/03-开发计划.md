# Showit 演示工作台开发计划

## 1. 交付原则

- 先抽离当前演示页的运行时，再建设项目编辑器。
- 每个阶段都有可运行版本和回归证据。
- URL、脚本和演示功能采用稳定合同，避免把当前单文件 DOM 结构直接复制为长期架构。
- 业务页面只作为连接器接入，Showit 不持有业务系统的业务数据。

## 2. 里程碑

| 阶段 | 周期 | 目标 | 主要产出 |
|---|---:|---|---|
| M0 技术基线 | 2 天 | 固化项目模型、运行时边界和安全规则 | JSON Schema、事件协议、连接器威胁模型 |
| M1 运行时抽离 | 1 周 | 将当前顶栏、底栏、中左、中右和观众屏抽成组件 | Presenter Shell、Stage、Notes、Footer、Audience |
| M2 项目与页面配置 | 1 周 | 配置项目、页面顺序、URL 和页面变量 | Project API、Page Editor、版本草稿 |
| M3 Markdown 脚本 | 4 天 | Markdown 编辑、渲染、步骤和自动保存 | Script Editor、Sanitizer、脚本预览 |
| M4 连接器与安全 | 1 周 | iframe、只读代理、登录状态、CSP 和健康检查 | Connector Service、代理策略、错误态 |
| M5 同步与计时 | 4 天 | 观众屏、同步协议、标注、计时和排练 | Session Service、BroadcastChannel、Rehearsal |
| M6 编辑器产品化 | 1 周 | 页面编排、项目发布、版本、权限和导出 | Project Workspace、Publish Flow、权限 |
| M7 设计实现与回归 | 1 周 | 按 Penpot 设计实现响应式 UI | Design Tokens、组件库、视口回归 |
| M8 验收与迁移 | 1 周 | 迁移当前 18 页演示并完成客户演示验收 | Golden Demo、部署包、手册、回滚方案 |

## 3. 开发任务

### M0 技术基线

- 定义 Project、Page、Connector、Script、Session、Rehearsal 类型。
- 定义同步事件：`ready、goto、reload、ping、pong、laser、circle、screen、bye`。
- 定义错误合同：连接失败、CSP 拒绝、业务写保护、脚本渲染失败、会话失效。
- 确定 Markdown Sanitizer、存储、认证和部署方式。

### M1 运行时抽离

- `PresenterTopBar`：项目、观众屏、自动翻页、检查、设置、重开和退出。
- `BusinessStage`：页面选择、刷新、系统登录、标注工具、iframe。
- `ScriptNotes`：标题、目标、Markdown 渲染、编辑、字号和保存状态。
- `PresentationFooter`：总计时、本页计时、翻页、排练和页码。
- `AudienceWindow`：全屏业务画面、结束页和同步恢复。
- 抽离当前 18 页演示回归脚本，确保迁移期间功能不丢。

### M2 项目与页面配置

- 项目列表、新建、复制、归档、权限和版本。
- 页面列表拖拽排序、复制、删除和预览。
- 页面 URL 模板、页面变量、连接器选择、角色和计时配置。
- 发布前检查 URL、脚本、页面顺序和连接器权限。

### M3 Markdown 脚本

- Markdown 编辑器支持快捷插入标题、列表和步骤区块。
- Markdown 预览与脚本步骤同步滚动。
- 保存草稿、版本对比、导入、导出和 XSS 清理。
- 脚本异常时保留原文并显示行号和错误原因。

### M4 连接器与安全

- 实现 iframe、popup、readonly-proxy 三种连接模式。
- 实现 CSP、sandbox、Origin、source、Cookie 和 Referrer Policy 检查。
- 实现登录/退出/角色状态合同。
- 实现业务页面健康检查、加载超时、备用 URL 和错误恢复。
- 连接器变更进入审计，发布版本锁定连接器快照。

### M5 同步与计时

- 建立演讲者/观众屏握手和状态重放。
- 实现页码、激光、圈选、黑屏、白屏、冻结和结束状态同步。
- 实现总计时、本页计时、章节计时、自动翻页阻塞条件和排练记录。
- 模拟观众屏关闭、网络延迟、重复消息、乱序消息和页面加载失败。

### M6～M8 产品化与验收

- 完成用户、团队、项目权限、发布和版本回滚。
- 按 Penpot 组件和设计令牌实现响应式界面。
- 将当前 18 页演示迁移为首个项目模板。
- 执行 1440px、1024px、375px 截图和交互验收。
- 输出安装部署、项目创建、演示运行、异常处理和回滚手册。

## 4. 测试计划

| 类型 | 用例范围 |
|---|---|
| 单元测试 | URL 模板、脚本解析、Markdown 清理、计时器、消息序列、权限判定 |
| 合同测试 | 项目、页面、脚本、连接器、会话和排练 API |
| 浏览器测试 | 四区布局、拖拽分栏、脚本编辑、页面切换、计时、标注和观众屏 |
| 安全测试 | XSS、恶意 URL、跨源消息、点击劫持、Token 泄露、只读代理绕过 |
| 故障测试 | iframe 404、CSP 拒绝、业务 5xx、观众屏断开、重复和乱序同步消息 |
| 回归测试 | 当前 18 页演示、五种业务角色、真实登录/退出和只读保护 |

## 5. 完成定义

- 文档、代码、配置、脚本和设计文件进入版本库。
- 新项目可以不改代码配置业务 URL 和 Markdown 脚本。
- 当前 18 页演示可从项目模板运行，全部现有功能通过回归。
- 观众屏、计时、排练、标注、自动翻页、异常恢复和快捷键均有自动化或可复现验证。
- 项目发布、权限、版本和回滚可用。
- 1440px、1024px、375px 视口没有横向溢出、文字遮挡和不可用控件。
- Penpot 设计与实现有页面、组件和 Token 对照表。
