## 2. 产品定义

Showit 是商业闭源的本地演示客户端，用于配置和演示任意 Web 业务系统。它由演讲者控制台、浏览器扩展、业务页面连接器、本机第二显示器和局域网只读观众屏组成。

第一版采用本地客户端优先模式：

- 项目、页面、Markdown 脚本、连接器、快照和排练记录保存在本机。
- 不建设团队协作、云端项目同步、多人编辑、团队权限和云端备份。
- 不建设 Showit 账号登录系统。
- 不提供本地应用锁。
- 不实现许可证技术校验，只随安装包提供商业许可声明和 EULA。
- 产品正式名称为 `Showit`。
- 第一版界面使用简体中文，代码和数据结构预留国际化；演讲脚本可以使用任意语言。
- 第一版不实现视频录制、不采集麦克风、不向观众传送音频。

## 3. 首版平台与交付物

### 3.1 正式支持平台

Windows：

- 64 位 Windows 10、Windows 11。
- x86_64 构建。
- Windows ARM 仅允许通过系统 x64 模拟尝试运行，不作为正式验收环境。
- 缺少 WebView2 Runtime 时由安装程序提示安装。

Linux：

- Ubuntu 22.04 LTS x86_64。
- Ubuntu 24.04 LTS x86_64。
- Debian 12 x86_64。
- AppImage 在三个环境完成验收。
- `.deb` 在 Ubuntu/Debian 完成安装、升级和卸载测试。
- Wayland 和 X11 均测试窗口、全屏和第二显示器。
- 其他发行版为尽力兼容；第一版不提供 Linux ARM64。

### 3.2 安装包

- Windows NSIS 当前用户安装包，不要求管理员权限。
- Windows 便携 ZIP。
- Linux AppImage。
- Linux `.deb`。
- 安装版关联 `.showit` 文件。
- 便携版默认使用用户目录，也允许启用便携数据目录。
- 所有交付包提供 SHA-256。

### 3.3 更新

- 启动后检查稳定版更新。
- 展示版本、更新时间和变更说明，由用户确认后下载和安装。
- 演示过程中不执行升级。
- Windows/Linux 更新包必须通过 Tauri 更新签名校验。
- 安装版支持更新；便携版提示下载新版本。
- 提供完整离线安装包。
- 浏览器扩展通过 Chrome Web Store、Edge Add-ons 或企业浏览器策略独立更新。

## 4. 技术架构基线

```text
Showit Desktop（Tauri 2）
├─ React 19 + TypeScript + Vite 8
├─ 演讲者四区运行时
├─ 项目编辑器与 Markdown 编辑器
├─ SQLite 本地工作库
├─ 本地观众屏 HTTP/信令服务
├─ 本机显示器窗口管理
├─ .showit 导入、导出、快照和加密
└─ Native Messaging Host / 本机控制通道
          │
          ▼
Chromium Extension（Manifest V3）
├─ Chrome / Edge / Chromium
├─ Side Panel 紧凑控制器
├─ tabs / scripting / tabCapture
├─ 操作录制与页面状态检测
├─ 按站点 optional host permissions
└─ 画面 WebRTC 上行
          │
          ├─ 最多 5 人：P2P WebRTC
          └─ 最多 20 人：按配置启动本地 SFU
                         │
                         ▼
              局域网只读观众页面
```

### 4.1 前端

- React 19、TypeScript、Vite 8。
- Ant Design 5 和 Ant Design Pro Components 用于项目列表、配置表单、表格、抽屉、弹窗、步骤和结果反馈。
- 演讲者运行时使用 Showit 自有组件和 Design Tokens，不设计成管理后台页面。
- React Router 7 管理项目、编辑器、运行时和观众路由。
- TanStack Query 管理服务端/持久化数据请求状态。
- Zustand 管理演示会话、当前页、当前步骤、计时、标注、布局和观众状态。
- `@dnd-kit` 实现页面编排和操作步骤排序。
- `react-resizable-panels` 实现中左/中右拖拽分栏。
- `react-markdown + remark-gfm + rehype-sanitize` 实现 Markdown。
- Zod + React Hook Form 实现合同和表单校验。
- Vitest、Testing Library、Playwright 实现测试。

### 4.2 桌面与本地服务

- Tauri 2 是第一版正式运行容器，不是后续可选项。
- Rust/Tauri 负责 SQLite、文件系统、显示器、窗口、自动更新、项目包加密和本地观众服务。
- 第一版不依赖 PostgreSQL、Redis、S3、Fastify 或 Showit 云端服务。
- 本地 HTTP/信令服务只在需要分享观众屏时启动，绑定用户选择的局域网接口。
- 浏览器扩展与客户端的控制通道优先采用 Native Messaging；WebRTC 信令通过本机短期会话服务。
- 20 人 SFU 属于第二阶段。先评估成熟开源 SFU 或成熟 WebRTC 库的体积、许可证和性能，不手写未经验证的 RTP 转发器。

### 4.3 浏览器扩展

- Manifest V3。
- 正式支持 Windows/Linux 上的 Chrome、Edge、Chromium。
- 开发期手动加载；正式版使用 Chrome Web Store、Edge Add-ons 或企业策略安装。
- 安装时不申请 `<all_urls>`。
- 添加连接器或首次访问站点时按 Origin 请求临时/持久授权。
- 跳转到未授权域名时暂停控制并请求授权。
- 不读取 HttpOnly Cookie，不保存业务账号、密码和 Token。

## 5. 演讲者运行时 UI

第一版直接以现有 LCAPIM 演示控制台截图和可运行页面作为视觉、交互和功能黄金基线。Penpot 不作为开发前置门槛，也不要求第一版维护 Penpot 文件。之前的 Penpot 项目已经作废并移入删除区。

### 5.1 四区结构

顶部区域必须保留：

- Showit/项目名称。
- 计划总时长、预计结束时间、当前章节和页码。
- 观众屏连接状态。
- 自动翻页状态和开关。
- 演前检查。
- 设置。
- 重新打开本机观众屏。
- 退出演示。

中左业务区域必须保留：

- 业务系统画面。
- 当前角色/会话/安全模式状态。
- 页面选择网格。
- 刷新。
- 系统登录/聚焦业务窗口。
- 激光笔。
- 圈选。
- 清除标注。
- 当前页面标题、角色、页码和只读/交互状态。

中右备注区域必须保留：

- 页面标题。
- 本页目的。
- Markdown 演讲脚本。
- 当前步骤、已完成步骤和下一步骤。
- 保存中、已保存、保存失败状态。
- 字号缩小/放大。
- 独立滚动位置。

底部区域必须保留：

- 演示总计时。
- 本页面计时。
- 本页剩余/超时。
- 首个页面、上个页面、下个页面、最后页面。
- 开始、暂停、继续计时。
- 重置计时。
- 排练和排练报告。
- 页面编号和完成百分比。

设置和辅助能力必须保留：

- 自动翻页总开关、全局间隔和单页间隔。
- 页面优先、均衡、备注优先布局。
- 观众屏正常、黑屏、白屏、冻结和结束。
- 键盘快捷键。
- 演前检查结果：正常、建议、异常。
- 最近排练记录和逐页耗时。

### 5.2 分栏尺寸

- 1440×900 下，中左业务区域约 75%，中右备注区域约 25%。
- 备注区默认约 360px，最小 280px，最大不超过主区域 50%。
- 分隔线交互热区 6px。
- 支持鼠标拖拽、键盘调整和双击恢复默认值。
- 比例按项目保存。
- 支持页面优先、均衡、备注优先预设。
- 1024px 保持左右分栏；低于 900px 改为业务区在上、备注区在下。
- 扩展 Side Panel 使用独立宽度。

### 5.3 视觉约束

- 保留深色演讲控制平面和高信息密度。
- 中左业务系统是首要视觉区域。
- 低圆角、细边框、紧凑工具栏、明确焦点和禁用态。
- 不加入营销式首页、装饰性大图、无业务意义的渐变或悬浮卡片。
- 项目管理页可以使用 Ant Design Pro；演示运行时不能直接套后台模板。

## 6. 双入口控制

Tauri 客户端和扩展 Side Panel 使用同一演示会话：

- Tauri 提供完整四区控制台。
- Side Panel 提供当前脚本、上一步/下一步、计时、页面状态和返回 Showit。
- 单屏用户可以主要使用 Side Panel。
- 双屏用户使用 Tauri 完整控制台。
- 两端页码、步骤、计时、标注和业务页面状态一致。
- 同一时刻只允许一个控制端执行自动操作，防止重复点击。

## 7. 业务页面连接方式

第一版提供三种连接方式：

1. 浏览器扩展模式：首选方式。业务系统作为顶层浏览器标签页运行，避免 iframe 的 CSP 和 `X-Frame-Options` 限制。
2. iframe 嵌入模式：用于明确允许嵌入的内部系统。
3. 独立窗口模式：扩展不可用或业务系统有特殊限制时使用。

不要通过删除目标网站 CSP 或 `X-Frame-Options` 作为正式方案。

### 7.1 浏览器会话模式

同时支持：

- 日常浏览器模式：复用当前 Chrome/Edge/Chromium 配置和已登录 SSO/MFA 会话。
- 专用演示模式：Showit 启动独立浏览器配置目录，Cookie、历史和缓存与日常浏览器隔离。

项目可设置默认模式，每次演示前可以切换。专用环境不会在演示结束时自动删除，用户可以查看占用并主动清理。

### 7.2 新标签与登录弹窗

- 同一已授权 Origin 打开的新标签/窗口由 Showit 自动接管并切换投送。
- 新 Origin 暂停控制并请求授权。
- SSO/MFA 登录弹窗完成后返回原业务标签。
- 切换期间观众屏保持安全遮挡或上一安全状态，新页面首帧就绪后才恢复。

## 8. 操作权限、录制器和步骤

### 8.1 权限级别

每个项目配置三级权限：

| 级别 | 能力 |
|---|---|
| 观察模式 | URL、标题、加载状态、元素定位和高亮 |
| 辅助模式 | 自动滚动、切换标签、刷新、前进后退和聚焦输入框 |
| 自动操作模式 | 点击、填写普通表单、选择和提交 |

- 默认辅助模式。
- 发布、删除、审批、付款等高风险操作必须现场确认。
- 即使项目允许自动操作，也不能绕过高风险确认。

### 8.2 操作录制器

第一版同时支持操作录制和手工编辑：

- 录制页面跳转、点击目标、普通输入、选择、滚动和等待条件。
- 不记录密码、Token、Cookie、文件内容和敏感输入值。
- 普通输入可以保存固定值、演示变量或只记录聚焦动作。
- 每个步骤可设置为提示、高亮、辅助执行或自动执行。
- 优先使用 `data-testid`、ARIA role/label 和稳定业务属性定位。
- 元素无法定位时暂停，不猜测并点击相似元素。

### 8.3 页面与步骤

- 项目包含多个页面。
- 每页绑定一个业务 URL、角色、计时配置和 Markdown 脚本。
- 每页包含多个演示步骤。
- “下一步骤”执行高亮、滚动、切换、跳转或获准的自动操作。
- 当前页面最后一步完成后，下一步骤变为进入下一页面。
- 底部翻页按钮始终可直接跨页。
- 返回页面时恢复上次停留的步骤。

步骤完成规则：

- 可用 URL、标题、元素、文本和状态作为预期条件。
- 满足条件后自动完成；没有条件时由演讲者手动完成。
- 自动操作成功后仍需验证预期条件。
- 条件超时保持当前步骤，提供重新检查。
- 演讲者可以强制完成并填写原因。
- 高风险步骤不自动进入下一步。
- 普通步骤可配置完成后自动进入下一步。
- 页面最后一步默认等待演讲者手动翻页。

## 9. Markdown 脚本

脚本提供三种视图，共用一份 Markdown 数据：

- 编排视图：讲述、操作、预期结果、转场、舞台提示和异常处理。
- Markdown 源码视图。
- 演示预览视图。

要求：

- 支持 GFM 标题、列表、引用、代码、表格、链接和强调。
- 无法识别的 Markdown 原文必须保留。
- 演示过程中可以临时编辑并自动保存。
- Markdown 渲染经过严格 HTML 清理。
- 用户可见脚本不与业务页面 CSS 相互污染。

## 10. 观众屏

### 10.1 显示内容

观众屏只显示演讲者完整页面中的中左业务系统画面，包括必要的激光、圈选、隐私遮挡、离线标识和屏幕状态。观众屏不显示：

- 顶部控制区。
- 中右 Markdown 备注。
- 底部计时和翻页。
- 项目编辑、连接器和权限配置。

### 10.2 输出方式

同时支持：

- 本机第二显示器全屏输出。
- 局域网浏览器只读链接。

拔出第二显示器后关闭本地观众窗口，不影响局域网观众；重新插入后由演讲者手动恢复。

### 10.3 临时链接

链接形式类似：

```text
http://<本机局域网IP>:<端口>/audience/<sessionToken>
```

- 每次演示会话生成随机不可猜测 Token。
- 结束演示、退出客户端或重新生成链接后旧 Token 立即失效。
- 观众不需要 Showit 账号。
- 观众不能控制页面、查看备注或访问项目 API。
- 分享界面显示链接、二维码、网络接口、容量模式、在线人数和连接质量。

### 10.4 容量模式

项目或每次会话可配置：

- 最多 5 人：P2P WebRTC。
- 最多 20 人：本地 SFU，浏览器上传一路，SFU 转发而不转码。

达到上限后拒绝新连接。20 人模式的 SFU 仅在开始投送时启动，结束后关闭。

### 10.5 加入方式

支持：

- 直接加入：默认，持有链接即可进入。
- 等待批准：演讲者根据显示名称、IP 和申请时间批准或拒绝。

演讲者可以查看在线人数、连接质量，断开单个或全部观众。观众名单只属于当前会话，结束后清除。

### 10.6 浏览器范围

桌面观众：

- Chrome 当前版本及前两个版本。
- Edge 当前版本及前两个版本。
- Firefox 当前版本及前两个版本。
- Safari 17+。

移动观众：

- Android Chrome 当前版本及前一个版本。
- iOS/iPadOS Safari 17+。

观众页面支持响应式适配、全屏、画质选择、连接状态和自动重连。移动端进入后台暂停视频，返回后恢复。

### 10.7 画面与音频

- 扩展通过 `tabCapture` 获取业务标签页画面。
- 观众接收实时像素流，不在自己的浏览器重新打开业务 URL。
- 业务 Cookie、Token、DOM 和登录状态不发送给观众。
- 第一版无音频、无麦克风、无录像。
- 激光、圈选、黑/白屏和冻结可以在观众层单独叠加。

## 11. 隐私与安全

### 11.1 整页隐私遮挡

以下情况自动或手动进入隐私遮挡：

- 页面出现密码输入框。
- SSO/MFA。
- 未授权新域名。
- 文件选择、证书选择或浏览器权限弹窗。
- 标记为仅演讲者可见的步骤。
- 演讲者手动开启。

遮挡期间停止发送新画面，观众显示项目品牌和“演示准备中”，不保留最后敏感画面。恢复必须由演讲者手动触发。

### 11.2 局部隐私遮罩

- 演讲者可以框选矩形区域。
- 可以绑定 DOM 元素并随滚动和尺寸变化移动。
- 支持纯色和模糊。
- 只作用于本机/局域网观众画面，演讲者业务页显示原内容。
- 元素定位失败时使用更严格的整页遮挡，不能暴露内容。
- 配置随项目导出，但不保存被遮挡文本。

### 11.3 敏感变量

- 密码、Token、Cookie、API Key 等只在演示开始时输入。
- 只存在当前进程内存。
- 结束、退出或超时后清除。
- 不进入项目、脚本、SQLite 快照、`.showit`、日志和诊断包。
- 第一版不接入 Windows Credential Manager 或 Linux Secret Service。

### 11.4 连接器安全模式

每个连接器支持：

| 模式 | 行为 |
|---|---|
| 交互模式 | 正常操作，只对自动高风险操作确认 |
| 请求保护模式 | 扩展按 URL、HTTP 方法和规则阻止请求；登录端点可放行 |
| 只读代理模式 | 专用代理阻止业务写请求 |

- 新连接器默认交互模式。
- 请求保护规则发布前通过演前检查。
- 只读代理只用于经过联调的系统。
- LCAPIM 内置示例继续使用已有的只读代理。
- 只读必须在扩展或代理层执行，不能只隐藏按钮。

## 12. 本地数据与项目包

### 12.1 SQLite 工作库

SQLite 保存项目、页面、脚本、连接器、布局、快照、演示记录和排练记录。使用操作系统用户目录及文件权限，不建设账号隔离。

### 12.2 自动保存和快照

- 修改后短延迟自动保存。
- 显示保存中、已保存和失败。
- 开始演示、导入、批量修改和数据格式升级前自动快照。
- 支持手动命名快照、说明、差异、恢复和复制为新项目。
- 默认保留最近 30 个自动快照；手动快照不自动删除。
- 运行中的演示固定使用启动快照。
- 编辑内容只有点击“应用修改到当前演示”后才进入运行会话。

### 12.3 `.showit` 文件

项目导入、导出、备份和换机使用 `.showit`：

```text
manifest.json
pages.json
scripts/*.md
assets/*
offline/*
```

- 默认不加密。
- 可选密码保护：Argon2id 派生密钥，AES-256-GCM 加密全部内容。
- 密码不保存且无法找回。
- Cookie、Token、业务密码和浏览器会话永不导出。

格式兼容：

- 包含 `formatVersion`。
- 同一主版本自动迁移。
- 迁移不覆盖原导入文件并生成报告。
- 旧客户端遇到更高格式只显示摘要，不写入。
- 新客户端至少支持最近两个主版本导入。
- 无法完整迁移时停止并列出不兼容项。

### 12.4 项目信任

导入第三方项目时先解析清单，不立即执行：

- 展示业务域名、离线 JavaScript、自动操作、外部网络权限和资源大小。
- Markdown、图片和视频可安全预览。
- JavaScript、自动操作和外部网络在信任前暂停。
- 信任与项目哈希绑定，内容变化后重新确认。
- 取消信任后仍可编辑和导出，不能执行脚本和自动操作。
- 内置 LCAPIM 示例由发行包签名并预置信任。

## 13. 离线备用画面

每个页面可以配置：

- 截图。
- 预录视频。
- 本地 HTML/CSS/JavaScript 包。
- 无备用内容。

演讲者手动切换备用画面；观众必须看到“离线备用”标识。

离线 HTML 允许执行 JavaScript，但必须在隔离环境中运行：

- 不暴露 Tauri API、SQLite、文件系统、项目数据、扩展控制通道和敏感变量。
- 包内 HTML、CSS、JS、字体和图片可加载。
- 外部网络按域名授权，默认未授权。
- 首次访问新域名由演讲者确认。
- 导入到新电脑后重新确认网络权限。
- 回环地址、局域网设备和 Showit 内部服务需要单独授权。
- 观众只接收渲染后的画面，不执行备用包代码。

## 16. 性能与体积目标

参考设备：4 核 CPU、8GB 内存、千兆或稳定 Wi-Fi 6，支持硬件视频编码时优先使用。

- Windows 安装包 ≤ 100MB。
- Linux 安装包 ≤ 130MB。
- 冷启动 3 秒内进入项目列表。
- 空闲内存 ≤ 250MB。
- 普通演示内存 ≤ 500MB。
- 5 人模式：1080p，目标 30 FPS。
- 20 人模式：1080p，目标 20 FPS；网络不佳时允许降为 720p。
- 局域网观众延迟 P95 ≤ 800ms。
- 页面切换后 1 秒内更新观众画面。
- 观众断线自动重连，不中断演讲者。
- 客户端/扩展异常不能影响原业务标签继续使用。

## 17. 隐私、日志和诊断

- 默认不上传使用数据和崩溃日志。
- 运行、扩展和观众连接日志只保存在本机。
- 默认保留 7 天，用户可以清理。
- 用户主动导出诊断包。
- 导出前列出内容。
- 自动脱敏业务 URL 查询参数、Cookie、Token、密码和脚本文本。
- 默认不包含业务截图或视频；只有用户明确勾选才包含。
